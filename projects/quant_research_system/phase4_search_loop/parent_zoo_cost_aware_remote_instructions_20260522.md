# Parent Zoo Cost-Aware Controller Remote Instructions 20260522

## Purpose

Run the next controller-only evolution milestone after the seed-zoo review.

The goal is not broad blind evolution. The goal is a small parent-zoo search that tests whether cost-aware mechanisms can preserve reversal structure while reducing turnover.

## Decision Context

Seed-zoo result:

- all 10 deterministic roots mechanically passed sample evaluation;
- none beat repaired attempt017 after 2.5 bps costs;
- several seeds had positive zero-cost gross Sharpe, but turnover consumed the edge;
- `five_day_excess_reversal` and `vol_norm_five_day_reversal` are useful roots, not promoted candidates;
- `kalman_ewm_reversal` is diagnostic only because high OS Sharpe came with negative IS Sharpe and high turnover.

Active roots:

```yaml
parent_roots:
  incumbent:
    root_id: attempt017_isos_repair
    program_id: PROG-20260430-CHILD-0017-ISOSREPAIR
  active_seed_roots:
    - five_day_excess_reversal
    - vol_norm_five_day_reversal
```

## Non-Negotiables

- Controller-only run.
- Do not launch `remote_sample_eval`.
- Do not launch full validation.
- Do not use test-set data.
- Keep the remote worktree clean and record `HEAD == origin/main`.
- Open and keep a dedicated vLLM server terminal before calling Qwen. A closed terminal means the Qwen server is not running.
- Qwen9B is the strict patch implementer. Larger-model output, if used, must be mechanism cards only, not code patches.
